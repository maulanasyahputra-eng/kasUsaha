Web Dev Cheat Sheet

Kamus lengkap tag HTML, properti CSS, dan fungsi JavaScript beserta contoh penulisannya.

HTML Cheat Sheet

1. Struktur Utama & Metadata

  • <!DOCTYPE html>
    Deklarasi versi dokumen HTML5.
    Contoh: <!DOCTYPE html>
  • <html>
    Elemen akar (root) pembungkus seluruh dokumen HTML.
    Contoh: <html lang="id"> ... </html>
  • <head>
    Wadah metadata, judul, file CSS, dan skrip yang tidak tampil di layar.
    Contoh: <head> ... </head>
  • <title>
    Menentukan judul halaman pada tab browser.
    Contoh: <title>Halaman Utama Saya</title>
  • <meta>
    Menyimpan metadata (charset, viewport responsif, SEO).
    Contoh: <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • <link>
    Menghubungkan berkas luar (seperti file CSS atau favicon).
    Contoh: <link rel="stylesheet" href="style.css">
  • <style>
    Menulis kode CSS internal di dalam file HTML.
    Contoh: <style> h1 { color: red; } </style>
  • <script>
    Menulis atau memanggil file skrip JavaScript.
    Contoh: <script src="script.js"></script>
  • <noscript>
    Teks alternatif jika JavaScript disembunyikan/dinonaktifkan oleh browser.
    Contoh: <noscript>Aktifkan JavaScript di browser Anda.</noscript>
  • <body>
    Menampung seluruh isi konten visual yang tampak di layar web.
    Contoh: <body> <h1>Halo Dunia</h1> </body>

2. Layout Semantik & Struktur Halaman

  • <header>
    Bagian kepala/atas halaman atau seksi.
    Contoh: <header> <h1>Logo & Judul Web</h1> </header>
  • <nav>
    Area tempat kumpulan menu navigasi.
    Contoh: <nav> <a href="#home">Home</a> | <a href="#about">About</a> </nav>
  • <main>
    Menampung konten utama yang unik dalam satu halaman.
    Contoh: <main> <p>Ini artikel utama.</p> </main>
  • <section>
    Menandai seksi/bab spesifik dalam halaman.
    Contoh: <section> <h2>Layanan Kami</h2> </section>
  • <article>
    Menampung konten mandiri (postingan blog, artikel berita, komentar).
    Contoh: <article> <h2>Judul Berita</h2> <p>Isi berita...</p> </article>
  • <aside>
    Menampung konten sampingan (sidebar, iklan, link terkait).
    Contoh: <aside> <h3>Artikel Populer</h3> </aside>
  • <footer>
    Bagian kaki/bawah dari halaman atau seksi.
    Contoh: <footer> <p>© 2026 Hak Cipta Dilindungi.</p> </footer>
  • <div>
    Kontainer blok umum untuk mengelompokkan elemen lain.
    Contoh: <div class="kartu"> <p>Teks di dalam kotak</p> </div>
  • <span>
    Kontainer inline untuk mengelompokkan sebagian teks.
    Contoh: Saya suka <span style="color:red;">merah</span>.

3. Teks & Format Konten

  • <h1> sampai <h6>
    Judul bab bertingkat (<h1> terbesar, <h6> terkecil).
    Contoh: <h1>Judul Utama</h1> <h2>Sub Judul</h2>
  • <p>
    Membuat paragraf teks.
    Contoh: <p>Ini adalah sebuah paragraf teks biasa.</p>
  • <strong> & <b>
    Menebalkan teks (strong = semantik penting, b = dekoratif visual).
    Contoh: <strong>Peringatan penting!</strong> <b>Teks tebal</b>
  • <em> & <i>
    Memiringkan teks (em = penekanan makna, i = dekoratif visual).
    Contoh: <em>Harap dibaca teliti.</em> <i>Ceteris paribus</i>
  • <mark>
    Memberikan warna sorotan (highlight) pada teks.
    Contoh: Kata kunci ini <mark>penting</mark>.
  • <small>
    Mengecilkan ukuran cetak teks (misal: syarat & ketentuan).
    Contoh: <small>*Syarat dan ketentuan berlaku.</small>
  • <del> & <ins>
    Menandai teks yang dihapus/dicoret (del) atau ditambahkan/garis bawah (ins).
    Contoh: <del>Rp 100.000</del> <ins>Rp 50.000</ins>
  • <sub> & <sup>
    Teks subscript (bawah) dan superscript (atas/pangkat).
    Contoh: H<sub>2</sub>O | 100 m<sup>2</sup>
  • <pre> & <code>
    Teks terformat presisi dan potongan kode komputer.
    Contoh: Ketik <code>npm install</code> untuk memasang.
  • <blockquote> & <q>
    Kutipan panjang berbentuk blok dan kutipan singkat inline.
    Contoh: <blockquote>"Pendidikan adalah senjata."</blockquote>
  • <abbr>
    Menandai singkatan beserta penjelasannya saat kursor diarahkan.
    Contoh: <abbr title="HyperText Markup Language">HTML</abbr>
  • <br> & <hr>
    Pindah baris baru (br) dan garis lurus horizontal pemisah topik (hr).
    Contoh: Baris Pertama<br>Baris Kedua <hr>

4. Tautan & Media

  • <a>
    Membuat tautan/hyperlink menuju web lain, file, atau bagian dokumen.
    Contoh: <a href="https://google.com" target="_blank">Buka Google</a>
  • <img>
    Menampilkan gambar pada halaman.
    Contoh: <img src="pemandangan.jpg" alt="Foto Pemandangan" width="300">
  • <audio>
    Memutar file suara/audio.
    Contoh: <audio src="musik.mp3" controls></audio>
  • <video> & <source>
    Memutar file video dan menentukan opsi file sumber media.
    Contoh: <video controls> <source src="video.mp4" type="video/mp4"> </video>
  • <iframe>
    Menampilkan halaman web lain/video YouTube di dalam halaman.
    Contoh: <iframe src="https://www.wikipedia.org" width="100%" height="300"></iframe>
  • <svg> & <canvas>
    Grafik vektor (SVG) dan area kanvas menggambar via JavaScript.
    Contoh: <canvas id="myCanvas" width="200" height="100"></canvas>

5. Formulir & Input

  • <form>
    Wadah pengumpulan dan pengiriman data dari pengguna.
    Contoh: <form action="/kirim.php" method="POST"> ... </form>
  • <label> & <input>
    Teks petunjuk penjelas dan elemen masukan data pengguna.
    Contoh: <label for="user">Nama:</label> <input type="text" id="user">
  • <textarea>
    Kotak isian teks multi-baris (untuk tulisan panjang).
    Contoh: <textarea rows="4" placeholder="Tulis pesan..."></textarea>
  • <button>
    Tombol interaktif yang dapat diklik.
    Contoh: <button type="submit">Kirim Data</button>
  • <select> & <option>
    Membuat menu pilihan drop-down.
    Contoh: <select name="kota"> <option value="jkt">Jakarta</option> </select>
  • <fieldset> & <legend>
    Mengelompokkan elemen formulir ke dalam satu garis kotak ber-judul.
    Contoh: <fieldset> <legend>Data Pribadi</legend> </fieldset>

6. Tabel, Daftar & Elemen Interaktif

  • <table>, <tr>, <th>, <td>
    Menyusun tabel data dengan baris (tr), header sel (th), dan sel isi (td).
    Contoh: <table border="1"> <tr> <th>No</th> <td>1</td> </tr> </table>
  • <ul>, <ol>, <li>
    Membuat daftar berpoin (ul) atau berurutan angka/huruf (ol).
    Contoh: <ul> <li>Apel</li> <li>Jeruk</li> </ul>
  • <details> & <summary>
    Membuat bagian ringkasan yang bisa diklik untuk buka/tutup (accordion).
    Contoh: <details> <summary>Baca</summary> <p>Isi teks</p> </details>
  • <dialog>
    Membuat kotak dialog/pop-up modal bawaan browser.
    Contoh: <dialog open> <p>Pesan Pop-up</p> </dialog>

CSS Cheat Sheet

1. Selektor & Pseudo-class

  • * (Universal Selector)
    Memilih seluruh elemen HTML di dalam halaman tanpa terkecuali.
    Contoh: * { margin: 0; padding: 0; box-sizing: border-box; }
  • .nama-class (Class Selector)
    Memilih elemen berdasarkan nama kelas (dapat dipakai berulang kali).
    Contoh: .tombol-utama { background-color: blue; color: white; }
  • #nama-id (ID Selector)
    Memilih elemen berdasarkan ID unik (hanya boleh 1 per halaman).
    Contoh: #header-layar { height: 80px; }
  • element (Tag Selector)
    Memilih seluruh elemen berdasarkan nama tag HTML-nya.
    Contoh: p { line-height: 1.5; }
  • :hover
    Memberikan gaya saat kursor mouse diarahkan di atas elemen.
    Contoh: button:hover { background-color: green; }
  • :focus
    Memberikan gaya saat elemen sedang aktif atau diklik (misal input teks).
    Contoh: input:focus { border-color: #007bff; outline: none; }
  • :nth-child(n)
    Memilih elemen anak ke-n berdasarkan urutan posisinya.
    Contoh: li:nth-child(odd) { background-color: #f2f2f2; }
  • ::before / ::after
    Menyisipkan konten dekoratif buatan sebelum atau sesudah elemen.
    Contoh: .judul::before { content: "★ "; color: gold; }

2. Tipografi & Teks

  • font-family
    Menentukan jenis font atau keluarga huruf yang digunakan.
    Contoh: body { font-family: 'Arial', sans-serif; }
  • font-size
    Mengatur ukuran besar/kecilnya huruf.
    Contoh: h1 { font-size: 32px; }
  • font-weight
    Mengatur tingkat ketebalan huruf (100 sampai 900 atau kata kunci).
    Contoh: p.tebal { font-weight: bold; }
  • font-style
    Mengubah gaya tampilan huruf menjadi miring atau normal.
    Contoh: span.miring { font-style: italic; }
  • color
    Mengatur warna teks.
    Contoh: h2 { color: #333333; }
  • text-align
    Mengatur perataan posisi baris teks (kiri, tengah, kanan, rata kiri-kanan).
    Contoh: .judul-tengah { text-align: center; }
  • text-decoration
    Menambah atau menghapus garis hiasan pada teks (seperti garis bawah/coret).
    Contoh: a { text-decoration: none; }
  • text-transform
    Mengatur huruf kapital pada teks (kapital semua, kecil semua, atau huruf awal).
    Contoh: h3 { text-transform: uppercase; }
  • line-height & letter-spacing
    Mengatur spasi vertikal antarbaris teks dan jarak horizontal antarhuruf.
    Contoh: p { line-height: 1.6; letter-spacing: 2px; }
  • text-shadow
    Memberi efek bayangan pada teks.
    Contoh: h1 { text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5); }

3. Warna, Latar Belakang & Border

  • background-color
    Mengatur warna latar belakang elemen.
    Contoh: .kartu { background-color: #ffffff; }
  • background-image
    Memasang gambar atau gradasi warna sebagai latar belakang.
    Contoh: .banner { background-image: url('gambar.jpg'); }
  • background-size & position
    Mengatur ukuran (cover, contain) dan posisi awal gambar latar.
    Contoh: .banner { background-size: cover; background-position: center; }
  • background-repeat
    Mengatur apakah gambar latar belakang diulang atau tidak.
    Contoh: body { background-repeat: no-repeat; }
  • border & border-radius
    Garis tepi (tebal jenis warna) dan kelengkungan sudut kotak.
    Contoh: .kotak { border: 2px solid #000; border-radius: 8px; }
  • outline
    Garis di luar border yang tidak memakan ruang layout saat fokus.
    Contoh: input { outline: 2px solid blue; }
  • opacity
    Mengatur tingkat transparansi elemen (nilai 0.0 sampai 1.0).
    Contoh: .gambar-transparan { opacity: 0.7; }

4. Box Model & Ukuran (Sizing)

  • width / height
    Menentukan lebar dan tinggi suatu elemen.
    Contoh: .kotak { width: 300px; height: 200px; }
  • max-width / max-height
    Menentukan batas maksimal lebar atau tinggi yang diperbolehkan.
    Contoh: .kontainer { max-width: 1200px; }
  • min-width / min-height
    Menentukan batas minimal lebar atau tinggi elemen.
    Contoh: .hero-section { min-height: 100vh; }
  • padding
    Jarak bagian dalam antara isi elemen dengan garis tepi (border).
    Contoh: .kartu { padding: 20px; }
  • margin
    Jarak bagian luar antara elemen dengan elemen di sekitarnya.
    Contoh: .kartu { margin: 15px auto; }
  • box-sizing
    Mengatur metode perhitungan ukuran kotak agar padding tidak menambah lebar.
    Contoh: * { box-sizing: border-box; }
  • box-shadow
    Memberikan efek bayangan di luar atau di dalam kotak elemen.
    Contoh: .kartu { box-shadow: 0 4px 8px rgba(0,0,0,0.1); }

5. Tata Letak (Display, Posisi, Flexbox & Grid)

  • display
    Menentukan mode sifat tampilan elemen (block, inline, flex, grid, none).
    Contoh: .sembunyi { display: none; }
  • position
    Menentukan aturan metode penempatan posisi elemen di layar.
    Contoh: .navbar-tetap { position: fixed; top: 0; }
  • top / bottom / left / right
    Koordinat pergeseran posisi pada elemen bermode position.
    Contoh: .modal-pop-up { top: 50%; left: 50%; }
  • z-index
    Mengatur urutan penumpukan elemen mana yang ada di depan/belakang.
    Contoh: .menu-pop-up { z-index: 999; }
  • overflow
    Mengatur perlakuan konten yang ukurannya melebihi batas kotaknya.
    Contoh: .kotak-scroll { overflow: auto; }
  • display: flex & flex-direction
    Mengaktifkan tata letak fleksibel 1D dan arah susunannya (row/column).
    Contoh: .kontainer-flex { display: flex; flex-direction: row; }
  • justify-content & align-items
    Perataan elemen flex horizontal (sumbu utama) & vertikal (sumbu silang).
    Contoh: .flex-tengah { justify-content: center; align-items: center; }
  • gap
    Menentukan jarak antar-item di dalam kontainer Flexbox atau Grid.
    Contoh: .kontainer-flex { gap: 16px; }
  • display: grid
    Mengaktifkan tata letak berbasis baris dan kolom dua dimensi.
    Contoh: .galeri-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

6. Animasi, Transformasi & Variabel

  • transform
    Mengubah posisi, rotasi, skala, atau kemiringan bentuk elemen.
    Contoh: .kartu:hover { transform: scale(1.05) translateY(-5px); }
  • transition
    Memperhalus durasi perubahan properti CSS saat terjadi interaksi.
    Contoh: .tombol { transition: background-color 0.3s ease; }
  • @keyframes & animation
    Mendefinisikan tahapan alur animasi kustom dan menjalankannya pada elemen.
    Contoh: .ikon-loading { animation: putar 1s infinite linear; }
  • cursor
    Mengubah bentuk kursor mouse saat diarahkan ke atas elemen.
    Contoh: .tombol-klik { cursor: pointer; }
  • filter
    Memberikan efek visual grafis pada gambar/elemen (buram, hitam putih, dll).
    Contoh: img.hitam-putih { filter: grayscale(100%); }
  • --nama-variabel & var()
    Membuat dan memanggil nilai variabel khusus yang dapat digunakan berulang.
    Contoh: :root { --warna: #007bff; } h1 { color: var(--warna); }
  • @media (Media Queries)
    Menyesuaikan aturan CSS berdasarkan ukuran layar perangkat (responsif).
    Contoh: @media (max-width: 768px) { .sidebar { display: none; } }

JavaScript Cheat Sheet

1. Deklarasi Variabel & Tipe Data

  • let, const, var
    Deklarasi variabel (let = diubah, const = tetap, var = cara lama).
    Contoh: let umur = 20; const pi = 3.14; var nama = "Budi";
  • String & Number
    Tipe data teks (diapit petik/backtick) dan tipe data angka.
    Contoh: let pesan = "Halo"; let harga = 50000;
  • Boolean
    Tipe data logika yang hanya bernilai benar (true) atau salah (false).
    Contoh: let isActive = true;
  • Array
    Tipe data koleksi untuk menyimpan banyak nilai sekaligus dalam satu variabel.
    Contoh: let buah = ["Apel", "Jeruk", "Mangga"];
  • Object
    Tipe data struktur pasangan kunci-nilai (key-value) untuk mendeskripsikan entitas.
    Contoh: let user = { nama: "Andi", umur: 25, kota: "Jakarta" };

2. Operator & Pengondisian

  • Operator Aritmatika (+, -, *, /, %, **)
    Melakukan operasi matematika (penjumlahan, pengurangan, sisa bagi, pangkat).
    Contoh: let total = 10 + 5; let sisa = 10 % 3;
  • Operator Perbandingan (==, ===, !=, !==, >, <)
    Membandingkan dua nilai. `===` membandingkan nilai beserta tipe datanya.
    Contoh: console.log(5 === "5"); // false (beda tipe data)
  • Operator Logika (&&, ||, !)
    Menghubungkan logika (DAN / &&, ATAU / ||, NEGASI / !).
    Contoh: let lulus = (nilai >= 75) && (absensi >= 80);
  • if ... else if ... else
    Menjalankan blok kode tertentu berdasarkan evaluasi kondisi logika.
    Contoh: if (nilai >= 80) { console.log("A"); } else { console.log("B"); }
  • switch & Ternary Operator
    Pilihan cabang logika kecocokan nilai & pengondisian if-else ringkas.
    Contoh: let status = (umur >= 17) ? "Dewasa" : "Anak";

3. Perulangan & Fungsi

  • for & while
    Mengulang kode sejumlah hitungan tertentu atau selama kondisi benar.
    Contoh: for (let i = 0; i < 5; i++) { console.log(i); }
  • for ... of & for ... in
    Perulangan setiap item di Array (for...of) atau kunci di Objek (for...in).
    Contoh: for (let item of buah) { console.log(item); }
  • Function Declaration
    Mendefinisikan fungsi umum yang dapat dipanggil di bagian mana saja.
    Contoh: function sapa(nama) { return `Halo, ${nama}!`; }
  • Arrow Function
    Sintaks ringkas modern untuk mendefinisikan fungsi.
    Contoh: const tambah = (a, b) => a + b;

4. Method Array & String Bawaan

  • push() / pop() & shift() / unshift()
    Menambah/menghapus elemen di akhir atau di awal array.
    Contoh: buah.push("Pisang"); buah.shift();
  • forEach(), map(), filter()
    Perulangan array, transformasi item ke array baru, dan penyaringan kriteria.
    Contoh: let ganda = angka.map(x => x * 2);
  • includes()
    Memeriksa apakah array/string memiliki nilai tertentu (true/false).
    Contoh: buah.includes("Apel"); // true
  • toUpperCase() & toLowerCase()
    Mengubah huruf menjadi kapital semua atau huruf kecil semua.
    Contoh: let teks = "Halo".toUpperCase(); // "HALO"
  • split() & replace()
    Memecah string menjadi array dan mengganti sebagian teks.
    Contoh: "A,B,C".split(","); "Halo Budi".replace("Budi", "Andi");

5. Manipulasi DOM (Document Object Model)

  • document.getElementById()
    Mengambil satu elemen HTML berdasarkan ID uniknya.
    Contoh: const header = document.getElementById("main-header");
  • document.querySelector() & querySelectorAll()
    Mengambil satu atau semua elemen HTML berdasarkan selektor CSS.
    Contoh: const tombol = document.querySelector(".btn-submit");
  • addEventListener()
    Memicu fungsi reaksi saat terjadi peristiwa/event tertentu (klik, ketik, submit).
    Contoh: tombol.addEventListener("click", () => alert("Klik!"));
  • innerHTML & textContent
    Mengubah konten kode HTML di dalam elemen atau teks polos.
    Contoh: header.innerHTML = "<span>Judul Baru</span>";

6. JavaScript Asinkronus & Waktu

  • setTimeout()
    Menjalankan fungsi satu kali setelah penundaan waktu tertentu (milidetik).
    Contoh: setTimeout(() => console.log("Halo"), 2000);
  • setInterval()
    Menjalankan fungsi secara berulang setiap interval waktu tertentu.
    Contoh: setInterval(() => console.log("Detik"), 1000);
  • fetch() & async / await
    Mengambil atau mengirim data ke server/API secara asinkronus.
    Contoh: async function get() { const r = await fetch(url); }
